# RFCs

Design proposals that must be accepted before implementation. An accepted RFC is normative;
changing its decisions requires a new RFC or an ADR.

| RFC  | Title                       | Status      |
| ---- | --------------------------- | ----------- |
| 0001 | Public chart and series API | Accepted    |
| 0002 | Datafeed contract           | Not written |
| 0003 | Indicators, drawings, panes | Not written |

Rules:

- One concern per RFC.
- Out-of-scope features are named explicitly, not implied.
- Every open question has a recommendation.
- No implementation lands before the RFC is accepted.
