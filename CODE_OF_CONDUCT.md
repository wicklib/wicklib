# Code of Conduct

This project follows the Contributor Covenant, version 2.1.

The full text is available at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Enforcement

Report unacceptable behavior to `conduct@wicklib.com`. All reports are reviewed promptly
and handled confidentially. Maintainers are obligated to respect the privacy and security
of the reporter.
