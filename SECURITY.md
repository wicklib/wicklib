# Security Policy

## Supported versions

Wicklib is pre-1.0. Only the latest published version of each package receives security
fixes.

## Reporting a vulnerability

Do not open a public issue. Report privately to `security@wicklib.com` with:

- the affected package and version,
- a reproduction or proof of concept,
- the impact you believe it has.

You will receive an acknowledgement within 72 hours. We will coordinate a fix and a
disclosure date with you. Credit is given unless you ask otherwise.

## Scope

The script runtime is designed to execute untrusted user code. Reports about sandbox
escapes, resource-limit bypasses, or cross-origin data access are treated as high
severity.
